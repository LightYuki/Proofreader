### 第一轮遗漏与范围偏差

- `.app button` 仍统一使用 4px 圆角，`.app button:hover:not(:disabled)` 仍统一增加底色。上一轮只给部分文字、图标按钮添加例外，没有建立完整的控件状态规则；普通工具栏按钮、弹窗按钮等仍会出现圆角底色反馈。
- 输入框没有专用 `:hover` 规则，但默认保留圆角边框，`:focus-visible` 会额外画出 2px 黑色外圈，并向外偏移 2px。文本输入框点击后也可能显示该聚焦效果。上一轮没有处理这层双框；仅区分 hover 与 focus 的技术名称不能解决用户看到的外观问题。
- 文件菜单、模型下拉、弹窗外层和状态提示仍使用小圆角；它们与菜单行本身的直角高亮需要分别确认，不能继续默认保留。
- 右键菜单及最近记录隐藏已有代码，不能据此把原《优化方案审查记录》中的草稿保护、异常恢复等事项标为完成。
- 第一轮只预览了空工作台的部分键盘流程，未确认有内容时的输入框、所有 hover 及桌面文件操作。构建成功、既有测试通过不能作为视觉效果符合需求的结论。

### 拟采用的完整状态规则

以下方案已获用户确认，尚未写入应用样式：按钮与输入框直角，菜单与弹窗外层 2px 小圆角；输入框保留单层细边框、悬停不变、聚焦只加深原边框。不使用统一圆角或焦点规则覆盖所有控件。

| 对象 | 默认 | 鼠标悬停 | 聚焦或选中 |
| --- | --- | --- | --- |
| 所有可编辑输入框，包括译文、风格、背景、地址、密钥、模型 | 单层细灰边框，保持当前尺寸和内边距 | 不变：不加背景、外圈或阴影 | 只让原边框加深；不增加向外偏移的第二圈，键盘输入位置仍可辨认。 |
| 只读文件路径 | 保留只读底色、单层边框与可选择文字 | 不变 | 无可编辑暗示；键盘焦点使用原边界，保留复制能力。 |
| 文字和图标操作，包括关闭、撤销、下拉箭头、行号、标签操作 | 原位置与点击范围 | 只改变文字或图标颜色，无悬停底框 | 键盘定位使用下划线等简洁提示；不向鼠标操作额外添加框。 |
| 普通实体按钮，包括浏览、取消、清除、上一条／下一条等 | 保留实体轮廓 | 建议仅改变原边框或文字明暗，不增加背景块 | 键盘焦点在原边界表达，不外扩；具体轮廓随圆角选择确定。 |
| 主要操作按钮 | 保留当前主要操作的静态填色 | 沿用此前确认的轻微明暗反馈 | 不叠加外围底框，保留清楚的键盘定位。 |
| 文件菜单、右键菜单、模型选项、最近列表、问题列表 | 紧凑原布局 | 直角整行浅灰高亮 | 菜单用行高亮定位；选中状态持续存在，不靠鼠标悬停才能看见。 |
| 文件标签、要求标签、筛选、正文当前行 | 保留当前项的静态标识 | 不出现独立圆角按钮底块；正文行反馈维持整行 | 保留当前文件、当前行与当前筛选的可辨识状态。 |

范围覆盖工作台、打开文件、最近打开、校润要求、设置、报错与恢复入口。输入框的系统文本右键菜单继续保留。菜单命令的可用条件、目标绑定、Esc 与焦点返回继续沿用已确认行为；有问题的流程逐项列出后调整，不以追加装饰替代行为优化。

### 样式实施方案（已确认，待实施）

建议采用简洁的黑白灰桌面控件样式。保留字体、字号、行高、间距、栏宽、控件尺寸和点击范围；本次先解决轮廓、颜色与状态规则，不借 CSS 整理重新排版。

1. **输入框只保留一层边界**：所有可编辑字段统一为 1px 细边框；hover 不变，聚焦仅把原边框从浅灰加深，不加外圈、阴影或底色。边框粗细不变，文字和尺寸不跳动。只读路径仍可选择、复制，禁用状态另定义，不把只读误当禁用。
2. **按钮按用途定义反馈**：文字／图标操作无底框；普通实体按钮保留原有白底和细边框，hover 仅边框或文字加深；现有深色主按钮才使用轻微明暗变化。不把所有按钮升级成深色主按钮，也不为 hover 增加缩放、位移或动画。
3. **菜单与列表保留行定位**：菜单项、模型选项、最近记录和问题列表始终直角；hover 使用较轻的中性灰整行高亮。已选中文件、筛选和正文行的静态标识保持稳定，不被 hover 覆盖。最近记录的打开与隐藏按钮维持原位置，但不各自浮出小底框。
4. **键盘焦点按控件表达**：输入框使用原边框；文字操作使用下划线；纯图标或实体按钮在原热区内部提供清楚、克制的定位，深色按钮采用可辨认的内侧浅色细线；菜单使用活动行。鼠标经过不显示键盘定位框。不能简单删除所有 focus 规则。
5. **圆角分开管理**：控件半径 0px，浮层／弹窗外层 2px；菜单行、选项与列表行始终 0px，状态灯和保存圆点仍为圆形。这是已确认的建议样式，不再沿用前一轮 4px 全局控件圆角。
6. **阴影只表达浮层关系**：输入框和按钮不加阴影；菜单／模型下拉减少现有投影的模糊与浓度，保留薄边框和很轻的短投影，帮助区分覆盖区域；弹窗维持遮罩，投影减弱。不增加发光、渐变或装饰层。
7. **重整默认规则而非继续堆例外**：取消全局按钮 hover 填色、控件共用的偏移外圈；基础样式保留字体、尺寸等静态规则，各类别显式声明默认、hover、focus-visible、active、selected、disabled。仅提取真正共用的交互色与控件／浮层圆角变量，不做全项目 CSS 架构重写，不添加框架或依赖。

覆盖清单：顶栏菜单；开始／停止／重试／保存；问题开关、上一条／下一条；文件标签及关闭；正文行号与当前行；问题列表与筛选；审阅编辑、采用、保留原译和恢复待审；撤销；文件选择与只读路径；最近打开及隐藏；风格与背景编辑；地址、密钥、模型、清除与获取模型；弹窗确认／取消／关闭；错误与恢复入口；菜单、模型列表、状态提示浮层。

应用代码暂未修改。讨论时提供独立的局部控件对照，演示现有和建议的悬停／聚焦；示意中的状态不代表真实文件操作。正式实现后的检查要覆盖实际页面的默认、鼠标、键盘、选中和禁用状态，不能只检查空工作台或引用旧构建结果；不新增测试文件。

| 最近打开的记录 | 打开或切换到此文件、复制译文路径、复制原文路径、从最近列表隐藏 | 对已打开记录显示“切换到此文件”；隐藏入口先沿用仅已关闭记录可操作的范围；记录不可读时显示原因并保留记录。 |
| 可编辑输入框 | 保留系统文本菜单：撤销、重做（如支持）、剪切、复制、粘贴、全选 | 操作当前输入框和选区，保留正常输入法及文本编辑习惯；密码框遵循系统限制。 |
| 空白处与没有相关操作的区域 | 不弹出无关的通用网页菜单 | 不显示刷新、后退、查看页面源码等与校润无关的网页命令；原生文件对话框和系统标题栏保持系统行为。 |

有文字选区时保留选区，复制仅使用右键所在区域的有效选区，不能引用其他输入框的旧选区。没有有效选区时不显示“复制选中文本”。其他命令也按当前对象和状态出现，不用大量无关灰项填满菜单。

本轮把“采用”“保留原译”“恢复待审”继续留在现有审阅操作区；右键提供复制、定位、文件操作。如果后续需要把审阅决定加入右键菜单，再逐项讨论。

暂不增加“关闭其他文件”“关闭全部文件”“全部采用”等批量操作。

### 共同行为

- 一次只打开一个应用菜单；右键其他位置时替换当前菜单。
- 打开菜单不修改审阅状态、不发模型请求、不保存或关闭文件；只有选择具体命令才执行。
- Esc 只关闭最上层菜单，不能同时关闭其所在弹窗；取消后回到触发位置。选择编辑命令则聚焦目标输入框。
- 支持方向键、Home／End、Enter，以及可适用位置的菜单键／Shift+F10；不能把文本输入框中的方向键拿来切换正文。
- 菜单靠近窗口边缘时向内调整，必要时限制高度；外部点击、正文滚动或目标失效时收起，避免浮在错误条目旁。
- 弹窗打开时，菜单属于当前弹窗范围，不允许穿透操作背后的工作台。
- 菜单开启后文件或条目发生变化时，执行前重新确认目标仍有效；不能把旧菜单命令应用到新文件。

## 文件与最近打开

文件菜单顺序为：

```text
打开…                         Ctrl+O
最近打开…
───────────────────────────────────
保存                          Ctrl+S
另存为…
───────────────────────────────────
关闭当前文件                  Ctrl+W
```

保留现有“最近打开”弹窗及其位置。文件菜单的“关闭当前文件”和标签右键的“关闭此文件”明确区分作用对象。进入弹窗或文件选择器的命令使用省略号，直接执行的命令不加省略号。

### 最近打开

- 继续按最近使用顺序显示原文／译文文件对；点击已经打开的文件对只切换，不重复创建标签。
- 保留现有文件名、路径和“已打开”说明；同名记录利用现有路径行和悬停说明区分，不增加新的主界面区域。
- 列表行使用直角整行反馈，避免每条记录像独立圆角按钮；打开入口与记录管理命令有明确作用区。
- 将现有移除动作改为“从最近列表隐藏”，保留草稿、建议、人工决定、校润要求、批次、当前行、输出路径和保存状态。列表内按钮保持原位置和热区，使用准确的悬停说明与无障碍名称；右键菜单使用完整文字命令。
- 隐藏同时作用于“最近打开”弹窗和空工作台的最近列表，不删除输入或输出文件，不改变打开标签，不停止任何检查。
- 隐藏状态跨重启保存。用户通过“打开…”再次选择同一文件对后，恢复已有进度并重新列入最近打开；输入有变化时仍执行既有文件身份检查，不能直接套用过期修改。
- 沿用仅对已关闭记录开放记录管理动作的范围；已打开记录提供切换和复制路径，不用隐藏命令代替关闭标签。
- 不新增“清除审阅进度”或清空全部记录的菜单项，也不增加管理页面。任何既有最近记录移除入口均不能继续隐式删除进度。
- 实现上将“列表可见性”与“会话是否存在”分开，不能继续调用当前删除整个会话的 `forgetSession`。旧记录默认可见；恢复、快照捕获和自动保存都要保留隐藏标记，不能重启或切换文件后意外清除标记。
- 隐藏操作写入失败时显示具体错误并恢复列表中的可见记录，避免界面已经隐藏而下次启动又出现；其审阅内容始终保留。

## 悬停样式调整

已确认移除轻量操作的悬停底框，同时保留菜单行定位、实体按钮反馈和键盘焦点。所有调整保持控件位置、尺寸和点击热区不变。

| 控件 | hover | 保留的其他状态 |
| --- | --- | --- |
| 顶栏“文件／校润要求／设置” | 文字颜色变化，无矩形底框 | 键盘焦点提示、菜单展开状态。 |
| 关闭、撤销、恢复待审及内联文字操作 | 图标或文字颜色变化，无底框 | 原有热区、禁用状态、操作说明。 |
| 文件标签的关闭按钮、正文行号 | 去除独立按钮底色，使用图标或文字反馈 | 当前标签与当前正文行的选中标识。 |
| 校润要求“风格要求／剧情背景”标签 | 仅文字反馈，不随 hover 出现底色 | 当前标签的下划线，键盘焦点。 |
| 模型下拉箭头 | 仅图标反馈，不产生按钮底框 | 输入框本身的边界、展开状态。 |
| 文件菜单、右键菜单、模型选项、最近记录 | 保留直角整行浅灰高亮，无圆角胶囊或独立描边 | 当前选项、键盘活动项、不可用状态。 |
| 待审／全部筛选 | 非选中项仅文字反馈 | 当前筛选保留清楚的静态标识；如保留底色，使用直角。 |
| 开始、停止、保存、采用等实体按钮 | 保留原按钮范围内的轻微明暗变化 | 不新增外围底框，不改变原有轮廓或位置。 |

不能通过全局移除 `outline` 来处理 hover。鼠标悬停、键盘焦点、当前选中和按下反馈需要分别定义；移除底框后，用户仍应能看出能点哪里、现在在哪个控件上。

菜单行保持紧凑，普通黑白灰色彩、细分隔线、短标签和右侧快捷键；不引入新的动画、发光、卡片化菜单或密集装饰图标。外层弹出菜单的细边框与现有小圆角暂时保留，与菜单项的 hover 底框分开处理。

## 其他菜单的优化边界

- **模型列表**：保留搜索与手填；键盘活动项自动进入可见区域；Esc 先关闭列表，再允许关闭设置弹窗；“已选中”和“当前键盘定位”分开表达。选中一个模型不自动保存整张设置表单。
- **文件标签菜单**：右键目标固定；关闭当前运行文件继续复用停止与保存进度的流程；右键关闭后台标签不停止当前文件的检查。
- **问题列表与筛选**：统一轻量操作的 hover 和焦点反馈；筛选只作用于问题列表，不改正文布局或过滤连续正文。
- **校润要求与设置弹窗**：保留现有结构，只统一标签、内联操作、关闭按钮、下拉列表和输入框的菜单行为。
- **菜单状态**：同一命令从文件菜单、右键菜单和快捷键触发时，应使用相同的可用条件与工作台动作；不可用状态不能通过右键绕过。
