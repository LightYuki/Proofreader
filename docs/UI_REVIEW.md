# 工作台视觉与交互检查

日期：2026-09-23。应用版本：1.0.0。范围：`src/` 中的工作台、审阅面板、文件标签与状态反馈。依据 `kill-ai-slop` 技能，以及用户确认的黑白灰界面、实色状态灯和悬停说明方案。

2026-09-24 第二轮实现：按钮与输入框改为直角，浮层／弹窗外层 2px；输入框保持单层边框，hover 不变、focus 只加深原边框。普通按钮仅边框反馈，文字／图标无 hover 底框，菜单／列表直角行高亮，选中状态稳定。保留布局、原控件尺寸和热区。新增正文临时查找／跳转层、轮次选择及恢复说明；浏览器用内存样例检查了实际组件和 900×620 最小窗口。测试未补写。下方扫描与静态验证为历史记录，本轮行为、构建与原生验收限制见 [实施记录](./OPTIMIZATION_REVIEW.md)。

## 当前规则

| 内容 | 实现 | 主要入口 |
| --- | --- | --- |

| 修改对照 | 灰底区分变化；新增用下划线，删除用删除线，同时保留文字图例，避免依靠颜色识别 | `ReviewPanel.tsx`、`App.module.css` |

| 顶栏焦点 | “文件”“校润要求”“设置”共用同一按钮样式，无悬停底框；键盘焦点使用下划线，关闭弹窗后返回入口，不显示矩形焦点框 | `App.module.css`、`App.tsx` |
| 信息层次 | 文件名和未保存圆点集中在标签；正文不重复显示无建议，灰色文件圆点与彩色审阅灯表达不同状态 | `DocumentTabs.tsx`、`BilingualReader.tsx` |
| 审阅动作 | 已采用后新增草稿重新进入待审；确认前正文与保存仍使用上次采用内容。采用后留在当前句，固定操作区避免按钮跳动 | `core/review.ts`、`ReviewPanel.tsx` |

无边框的关闭图标、撤销和文字操作统一采用文字／图标反馈，不新增悬停底框；文件菜单项使用直角行高亮。打开文件弹窗只保留简短标题说明、两组文件选择及操作，移除 JSON 字段格式和新标签进度说明。

剧情背景默认空白，无示例文字。保持现有左右对照阅读、右侧审阅、文件菜单、校润要求与模型设置的独立分工；不增加配色或语言设置页。

## 扫描结果与保留理由

扫描 28 个前端文件，2 组、5 处匹配：

- 规则 09 共 3 处：顶栏键盘焦点下划线、修改对照新增下划线及真实增删图例。三者都传递实际交互或内容变化，不属于装饰性强调。
- 规则 19 共 2 处：文件未保存圆点与审阅灯。这是用户需要的功能性信号，不属于过度圆角。

没有新增渐变、光晕、胶囊标签、装饰图标或依赖。保留 Windows 系统字体。错误文字与差异文本也使用灰阶，彩色只用于审阅灯。
